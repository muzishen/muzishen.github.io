SCENARIOS

一套系统，三类场景复用

同一套大模型能力，按场景配置不同的检测项与告警规则。小区重周界与车行，敬老院重长者看护，校园重秩序与行为规范。

住宅小区

周界围墙、地库出入口、单元门厅、非机动车棚。夜间重点防翻越、防入侵、防车辆异常滞留，消防通道占用随手可查。

翻越围栏区域入侵车辆检测车牌识别消防通道占用

养老敬老院

房间、走廊、楼梯、活动室与庭院。护理人力有限，靠持续看护兜住摔倒、卧地未起、久卧不动、夜间离床与误入高危区域，并支持老人语音呼叫。

疑似摔倒卧地未起夜间离床长时间无活动语音求助危险区域

校园

校门口、操场、楼道、教学楼顶连廊、校园湖边与宿舍区。除校外人员与车辆管控外，重点盯防高空攀爬、临水危险、抽烟、冲突与楼道拥挤等极端风险。

人形检测 实时

画面中稳定框出并跟踪每一位人员，区分人体与广告牌、树影、招贴等干扰，为后续的行为分析提供目标基础。

多目标跟踪抗遮挡夜间增强

车辆检测 实时

识别轿车、SUV、货车、电动车等车型，统计出入与停放状态，车辆在禁停区超时滞留即时提醒。

车型分类滞留检测车流统计

车牌识别 实时

抓拍并识别车牌号码与号牌颜色，支持无感通行、访客登记、黑名单车辆比对与出入记录回溯。

号码识别号牌颜色黑白名单

图片 / 视频内容描述 大模型

用一句句自然语言说清画面里发生了什么，把看不懂的监控变成可检索、可回溯的文字记录，支持自然语言搜录像。

多模态理解自然语言语义检索

区域人数统计 / 点名核对 实时

按区域统计在场人数、进出双向流量与平均停留时长，支持与名单基数核对，用于校园点名、场所超员与夜间滞留核查。

人流计数进出双向名单核对

火焰检测 紧急

识别画面中的明火与烟雾，低照度、夜间环境同样有效，触发后第一时间推送并联动现场处置。

明火 / 烟雾夜间有效联动告警

烟雾 / 消防通道占用 告警

在没有明火之前就抓住隐患：识别初期烟雾，以及杂物、车辆堆放占用消防通道与安全出口，契合消防检查的日常要求。

初期烟雾通道占用消防合规

指定区域入侵 告警

自由绘制电子围栏与警戒区，人员进入即刻告警；支持多区域、分时段、分级别的规则配置。

电子围栏多边形区域分级告警

翻越围栏检测 紧急

识别攀爬、跨越围墙与护栏的肢体动作，夜间周界防护的核心能力，先告警、后人工复核。

动作识别周界防护夜间

抽烟行为 告警

在楼道、仓库、加油站、林区等禁烟场所识别点烟与吸烟动作，及时消除消防隐患。

行为识别禁烟区消防隐患

疑似打架 / 肢体冲突 紧急

识别推搡、挥击、纠缠、多人围堵等激烈肢体动作，输出“疑似”结论并附关键帧，交由人工复核确认。

动作识别疑似告警关键帧回传

楼梯 / 走廊人员聚集 告警

统计区域人数与停留时长，拥挤、聚集超过阈值即提醒，可用于楼道防踩踏、宿舍区夜间聚集与滞留监测。

人流计数停留时长密度阈值

疑似跳楼 / 高空攀爬 紧急

识别天台、连廊、阳台栏杆处的攀爬、跨越护栏、长时间停留于外沿等动作，秒级推送校方值班与安保，为现场干预争取时间。

护栏跨越外沿停留秒级推送

疑似跳湖 / 落水检测 紧急

识别校园湖岸、河边、水塘栏杆处的翻越动作，以及人员入水后水面持续异常波动，联动广播喊话与救援派单。

临水翻越入水判定广播联动

老人疑似摔倒 紧急

识别突然倒地、躺卧不起等姿态，秒级通知护理员与家属端，附事发前后关键帧，便于判断伤情。

姿态识别躺卧检测紧急联动

摔倒后长时间未起 紧急

摔倒只是第一步判断。若倒地后超过阈值仍无自主起身，事件自动升级并扩大通知范围——从“发现”走到“确认”，而不是丢一条告警就结束。

卧地时长告警升级闭环确认

老人长时间无活动 告警

在房间、沙发、床边等固定区域监测长时间静止状态，超过阈值主动提醒巡查，预防意外无人发现。

静止监测时长阈值主动关怀

夜间离床 / 离床未返 告警

夜间识别老人离床、起夜后长时间未返回床位，或独自走向卫生间、阳台与房门，及时提醒护理员，降低夜间跌倒与走失风险。

床位空置返床计时夜间看护

老人进入危险区域 告警

标注水池、天台、配电房、马路边等高风险区域，老人靠近或进入即预警，及时干预、避免走失与意外。

危险区标注边界预警防走失

老人语音求助 / 语音交流 大模型

房间麦克风阵列随时可呼叫："我有点不舒服"即被识别为求助意图，自动通知值班护士并同步生成护理记录，老人不必找手机、不必按按钮。

语音唤醒意图识别双向对话

PIPELINE

01

摄像头接入

RTSP / ONVIF 接入现有枪机、球机与门禁摄像机，支持多路并发。

02

抽帧与切片

按秒级抽帧，事件触发时自动截取前后片段，避免全量上云。

03

大模型理解

视觉检测 + 多模态语义判断：谁、在哪、在做什么、是否异常。

04

事件与规则

05

通知与日报

App / 短信 / 企业微信推送，次日自动生成安全事件日报。
